\doxysubsection{Detailed Description}
Clase principal del programa encargada de gestionar un menú interactivo para comprar, vender y consultar información relacionada con acciones.

El programa permite al usuario realizar las siguientes operaciones\+:


\begin{DoxyItemize}
\item Comprar acciones 
\item Vender acciones 
\item Consultar las ganancias totales 
\item Salir del programa 
\end{DoxyItemize}

Las operaciones se gestionan mediante una instancia de {\ttfamily \doxylink{class_colas_1_1_cola}{Cola}}, que contiene la lógica de almacenamiento y actualización de acciones.
