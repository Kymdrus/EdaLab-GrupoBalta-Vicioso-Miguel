Detailed Description

Clase principal del programa encargada de gestionar un menú interactivo para comprar, vender y consultar información relacionada con acciones.

El programa permite al usuario realizar las siguientes operaciones:

  • Comprar acciones
  • Vender acciones
  • Consultar las ganancias totales
  • Salir del programa

Las operaciones se gestionan mediante una instancia de Cola, que contiene la lógica de almacenamiento y actualización de acciones.
