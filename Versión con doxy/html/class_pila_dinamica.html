Detailed Description

Esta clase hace una implementación dinámica de la pila, se implementan los métodos de la interfaz "Interfaz_pila Esta implementación de pila contiene un nodo que se corresponde al de más arriba de la pila y una variable que nos indica el tamaño según vamos añadiendo elementos a la pila.
